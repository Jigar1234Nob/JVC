# Android build

The Android shell is generated by Capacitor 7. The checked-in native overlay under this folder replaces the generated MainActivity and WebView clients after the project is generated.

From the repository root:

~~~bash
npm install
npm run build
npx cap add android
npx cap sync android
bash apps/android/apply-native-overlay.sh
npx cap open android
~~~

CI runs the same generation and overlay steps before building the debug APK.

## Permission behavior

Only the exact HTTPS origin https://chat.jigar.au can request media capture. Only Android WebView AUDIO_CAPTURE and VIDEO_CAPTURE resources are accepted. Unknown resources and all other origins are denied. Android runtime permissions are requested only for the requested resource, and the WebView request is granted only after the OS grants it.

The WebView navigation policy keeps the Capacitor app origin and https://chat.jigar.au inside the app. External HTTP(S), mailto and tel links are sent to Android's default handler. Other schemes are blocked.

## Limitations

- The current CI output is a debug-signed APK, not a production upload APK/AAB.
- No native background push-notification bridge is included. WebView notifications must not be advertised as reliable background push.
- Clipboard read/write depends on Android System WebView support, secure context and user-gesture rules. Test it on physical devices.
- The strict media gate only permits requests whose requesting frame origin is chat.jigar.au. Third-party call frames are denied by design until separately reviewed and explicitly allowlisted.

See docs/RELEASE.md for signing, privacy disclosures, embedding headers and the full device QA checklist.
